#Bank Blood Network 🩸 #An integrated management ecosystem featuring donor profile management, real-time hospital inventory tracking, and AI-powered blood analytics to streamline critical operations across blood banks, hospitals, and blood donors.  🚀 Key Features1. Donor Portal & EngagementDigital Profile & QR ID: Instant QR code configuration utilizing qrcode.react for fast on-site check-in registration.  Smart Booking & Eligibility: Real-time eligibility tracking based on last donation dates and integrated mapping for appointment scheduling.  Gamification UI Framework: Tailored tracking systems for custom points and badges redeemable for health rewards and healthcare partner discounts.  2. Inventory & Hospital ManagementLive Dashboard: Built-in charts powered by recharts for monitoring active blood units by type with low-stock alerts.  Smart Expiry Tracking: Early-warning tracking system that implements strict First-In-First-Out (FIFO) consumption logic.  SOS Requests: Instant emergency escalation dispatching geo-targeted alerts to local donors for rare blood types.  3. Machine Learning & Intelligent AutomationShortage Prediction: Trend forecasting models to predict inventory dips during holidays or seasonal trends.  Smart Donor Matching: Algorithmic ranking that selects high-probability donors based on proximity and historic responsiveness.  Blood Quality Analysis: Computer Vision model powered by ultralytics (YOLOv8) and opencv-python assisting in accelerated laboratory sample classification.  PDFVoice-Enabled NLP Chatbot: An intelligent medical inquiry chatbot that answers donor questions regarding eligibility.  PDF🛠️ System ArchitectureThe project utilizes a decoupled 3-Tier Architecture:Frontend: Built with Next.js 16 and styled with Tailwind CSS v4.  Core Backend API: Engineered using the .NET (C#) ecosystem.  Machine Learning Microservices: Powered by Flask / Python.  Database: Relational storage using SQL Server.  📦 Project Dependencies🖥️ Frontend (Next.js)next: 16.1.6   react / react-dom: 19.2.4   tailwindcss / @tailwindcss/postcss: ^4.2.0   lucide-react: ^0.564.0   qrcode.react: ^4.2.0   recharts: 2.15.0   react-hook-form & zod (For robust registration schema verification)   ⚙️ Main Backend API (.NET Core).NET SDK 8.0 or higherMicrosoft.EntityFrameworkCore.SqlServer   System.IdentityModel.Tokens.Jwt (For secure RBAC authorization)   🧠 Machine Learning Engine (Flask & Python)flask == 3.1.3   ultralytics == 8.4.33 (For computer vision models)   opencv-python == 4.13.0.92   torch == 2.11.0 / torchvision == 0.26.0   🏃 Way to Run the ProjectFollow these steps to spin up the entire application locally on your machine.PrerequisitesNode.js (v18+ or later).NET SDK (v8.0+)Python (3.9+ or later)SQL Server Instance running locallyStep 1: Database SetupOpen your local SQL Server instance.Confirm or create a new database named BloodBank.  Verify your database connection settings inside appsettings.json matches your local server instance:  JSON"ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=BloodBank;Trusted_Connection=True;TrustServerCertificate=True;"
}
If you have any automated mailing functionality setup, verify the internal SMTP configurations in that same file.  Step 2: Run the .NET Core Backend APIOpen a terminal window and navigate to your core backend repository folder:Bashcd backend/BloodBankAPI
Restore NuGet packages and apply the structural migrations to target your database instance:Bashdotnet restore
dotnet ef database update
Boot up the service infrastructure hosting environment:Bashdotnet run
The core web application api service will start running based on your configuration parameters (defaulting onto local web targets like http://localhost:5004).  Step 3: Run the Machine Learning Microservice (Flask)Open a separate terminal window and navigate to your Python ML service folder:Bashcd backend/ML_Service
Build and trigger a localized isolated python virtual environment workspace:Bashpython -m venv venv
# On Windows environments:
venv\Scripts\activate
# On Mac/Linux environments:
source venv/bin/activate
Batch-install all required requirements from your dependencies file:  Bashpip install -r requirements.txt
Fire up your Flask service runner application script:Bashpython app.py
The ML endpoints will initialize and run on http://127.0.0.1:5000 or your configured local port.Step 4: Run the Next.js Frontend ClientOpen a third terminal window and navigate to your frontend project root directory:Bashcd frontend
Install the necessary node modules specified in your configuration:  Bashnpm install
Launch your local compilation environment server client:  Bashnpm run dev
Open up your web browser workspace and point it directly to: http://localhost:3000   🔮 Future RoadmapReal-time Push & SMS Notifications: Migrating from basic email infrastructure to Firebase Push Notification APIs and native mobile SMS gateway integrations.Live Geofencing Location Triggers: Tracking spatial real-time coordinates of active donors via GPS to automatically pinpoint the closest blood bank network branches.Healthcare Commercial Integration: Formulating collaborative point-exchange ecosystems allowing donors to redeem gamified rewards at external pharmacies and medical clinics.
